# Ethics and Responsible Use

AgentGuardBench is a defensive evaluation resource. It must not be used to target systems without explicit authorisation, collect real personal data, bypass access controls, or automate harmful actions.

The bundled dataset is synthetic. Example credentials, identifiers, people, and organisations are fictitious. Researchers extending the benchmark should document data provenance, minimise personal data, obtain required approvals, and publish known limitations.

Benchmark scores are evidence about a tested configuration, not proof that an AI system is universally safe, ethical, compliant, or secure.
